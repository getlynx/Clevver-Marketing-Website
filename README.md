# Clevver Marketing Website

A professional marketing landing page for [Clevver](https://clevver.org) — a permanent, encrypted document storage platform powered by distributed ledger technology.

## Overview

Clevver provides permanent document storage with AES-256 encryption by default. Documents are stored once with a one-time fee and remain accessible forever at no additional cost. The platform is designed for law firms, healthcare organizations, academia, real estate professionals, and corporate enterprise.

**Key value propositions:**

- **Permanent storage** — Documents stored immutably for centuries
- **AES-256 encryption by default** — All data encrypted automatically before storage
- **One-time cost** — Pay once to store, retrieve for free forever
- **Zero-knowledge architecture** — Clevver cannot access your encrypted documents
- **Distributed redundancy** — Data stored across a geographically distributed network

## Tech Stack

- **HTML5** — Semantic markup with accessibility attributes
- **CSS3** — Custom properties, Flexbox, CSS Grid, responsive design
- **JavaScript (ES6+)** — Vanilla JS, no frameworks or dependencies
- **Fonts** — Inter (body), Crimson Pro (headings) via Google Fonts

No build tools, bundlers, or package managers required.

## Page Sections

1. **Navigation** — Fixed header with mobile hamburger menu
2. **Hero** — Value proposition with AES-256 badge, demo CTA, trust indicators
3. **Trust Bar** — Partner organization names
4. **Solutions** — 6 feature cards (tagging, permanent URLs, retention, encryption, API, batch processing)
5. **Security** — AES-256 encryption, zero-knowledge architecture, distributed redundancy
6. **Compliance** — Healthcare (HIPAA), Legal (attorney-client privilege), Enterprise & Academia (permanent records)
7. **Testimonials** — Customer quotes from healthcare, legal, and academic professionals
8. **Pricing** — 3 tiers: Free (10 MB), Standard ($5/MB one-time), Enterprise (custom API pricing)
9. **CTA** — Demo scheduling link
10. **Footer** — Links, contact info, badges

## Pricing Model

- **Free** — First 10 MB of permanent storage at no cost
- **Standard** — $5 per MB, one-time payment, free retrieval forever
- **Enterprise** — Custom pricing with API integration and monthly billing at negotiated rates
